# AGENTS.md

All project instructions live in `CLAUDE.md` at this directory's root. Read it in full before doing anything else; it is the single source of truth for:

- project rules and workflow (also see `PROJECT_RULES.md`)
- permissions, guardrails and what you may or may not touch
- dependencies and environment requirements (e.g. MATLAB/Simulink versions)
- build, test and run commands
- coding and commenting standards

Where `CLAUDE.md` mentions Claude-specific tools (hooks, subagents, MCP servers), follow the underlying rule with your own equivalent, or stop and ask the user if you cannot. Do not edit `CLAUDE.md` or this file unless asked.
